# 0_수집분석 — 미리 모아 둔 게시물과 분석

앤서니 팀이 뵤리약사(@byori_yaksa) 공개 게시물을 모으고 **사실만** 분석한 자료다(게시물 그림, 캡션 통계, 그림 크기·색 실측, 글자 크기·여백 실측, 게시물 종류 판정). 부품 후보·대표 편 목록·디자인 설계 초안처럼 우리가 판단한 문서는 넣지 않았다 — 그 판단은 이 묶음의 클로드가 `1_공통설계서/설계하기.md`대로 새로 한다. 약사님이 게시물을 다시 모으지 않아도 되게 넣었다. **이 폴더의 파일은 원본이므로 고치지 않는다**(잘라 쓸 때는 복사해서 쓴다).

- 모은 날: **2026-11-03**(게시물 목록·캡션 전문·슬라이드 그림 모두 그날 Apify로 받음). 그 뒤에 올라온 게시물은 없다.
- 공개 카드뉴스(캐러셀) 슬라이드와 캡션만 있다. 릴스·스토리·개인 게시물·따로 받은 본인 사진은 없다.
- 게시물 목록은 계정 전체 343개 중 최근 150개(2026-02-08까지)다.

## 편 폴더 이름 규칙

`게시물/<게시 날짜>_<아이디>/`
- 게시 날짜 = 한국 날짜(`YYYY-MM-DD`). 아이디 = 인스타 주소 `instagram.com/p/<아이디>/`의 그 글자.
- 안에 `1.jpg, 2.jpg …` = 장 순서 그대로.
- `출처.json` = 주소·분류·장 수·받은 날·원본·**`영상 장`**(영상이라 미리보기 그림만 있는 장 번호 — 작고 흐리므로 색·크기를 재거나 견본·블라인드에 쓰지 않는다). 게시일·원본 해상도가 적힌 편과, 대신 `하위 유형`(분류.md의 같은 칸)이 적힌 편이 있다. `원본해상도`는 첫 장 기준이라 다른 장 크기와 다를 수 있다 — 장 크기는 그림을 열어 본다.
- **`2026-08-24_DcbAUljoJe6`만 다르다**: 2장짜리 게시물인데 `1.jpg`(영상 첫 장면 미리보기, 720×960)만 받았고 2장과 `출처.json`이 없다. 이 편은 쓸 장이 없다.
- `글.md`(장별 글을 받아 적은 것)는 `2026-08-28_DclNSEpINzJ`·`2026-09-01_DcvlvWUoIhU`·`2026-09-08_DdBqt43E004`·`2026-09-11_DdJT21ZE5Rv`·`2026-11-02_DfOE-NME-WO`에만 있고, 그중에서도 받아 적은 장만 있다(머리에 적힘). 다른 장의 글은 그림을 열어 읽는다.
- 그림 크기는 편마다 다르다(1080×1350, 1640×2047, 1206×1508 등). 4:5가 대부분이고 3:4·4:5에 가까운 크기·그 밖의 크기가 섞여 있다 — 편별 표와 쓰면 안 되는 장은 `3_작업안내/뵤리약사_작업안내.md` 1·2장.
- 종류는 `분류.md`가 기준이다(`출처.json`의 `분류`와 같다).

## 분석 문서 속 옛 경로 읽는 법

분석 문서는 우리 쪽 보관 폴더 이름으로 경로를 적었다. 이 묶음에서는 아래처럼 읽는다.

| 문서에 적힌 경로 | 이 묶음 안 자리 |
|---|---|
| `01/게시물목록.json`·`01_수집_인스타게시물/…`·`01/프로필.md` | `0_수집분석/게시물목록.json`·`프로필.md` |
| `02/슬라이드/<편>/`·`02_대표게시물_슬라이드/슬라이드/<편>/`·`…/정보형_추가/<편>/` | `0_수집분석/게시물/<편>/`(두 곳을 한 폴더로 모음 — 두 곳에 다 있던 `DdJT21ZE5Rv`는 같은 파일이라 하나만 둠) |
| `02/분류.md` | `0_수집분석/분류.md` |
| `03_분석_계정특징/2026-11-03_1단계_실측.md` 등(`2026-11-03_` 머리) | `0_수집분석/1단계_실측.md`·`캡션통계.md`·`슬라이드실측.md` |
| 계정별메모·커스텀 설계서(우리가 쓴 설계 문서) | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다(`7_결과/설계/`·`2_커스텀설계서/`) |
| `설계서/공통/작업_설계서.md`·`도구/…`(수집검증·캡션통계 도구 등)·`git-docs/…` | 묶음에 없음(우리 쪽 작업 문서·도구) — 필요 없다 |
| `한눈에보기/`, `_결정전`·`_수정전`·`_이전` 같은 옛 판, Apify 원본 json, 검수 기록(`04_설계서검토/…`), `05_동의와설정/…`, `수집검증` | 묶음에 없음(넣지 않음) |
| 우리가 만든 디자인 시스템 화면·부품 견본·그림 조각·완성 캐러셀 | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다 |

- 문서에 나오는 `계정A`~`계정G`(뵤리 = 이 계정 자신이라 이름 그대로)는 다른 약사님 계정 이름을 가린 것이다. "앤서니"는 그룹스터디 진행자다(막히면 연락할 사람).
- 분석 문서의 숫자(편 수·장 수)는 그 문서를 쓴 때 기준이라 서로 다를 수 있다(예: 슬라이드실측은 21편 107장, 이 폴더 게시물은 42편 184장).
- 캡션통계·슬라이드실측의 `[도구]` 칸 안내, "대표 hex" 같은 말은 우리 쪽 도구가 쓴 말이다. "대표 hex"는 32단위로 뭉친 색 값이라는 뜻이고 대표 편과는 상관없다.
